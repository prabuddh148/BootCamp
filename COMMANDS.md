# Quick Commands

**Compile and Run:**
```powershell
.\run.bat
```

Or in terminal:
```
javac -d out src/main/java/com/example/bootcamp/*.java
java -cp out com.example.bootcamp.HelloWorld
```

**Just Compile:**
```
javac -d out src/main/java/com/example/bootcamp/*.java
```

**Just Run (if already compiled):**
```
java -cp out com.example.bootcamp.HelloWorld
```
